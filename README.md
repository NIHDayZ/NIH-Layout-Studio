# NIH Layout Studio

NIH Layout Studio is a browser-based visual editor, renderer, resource inspector, and authoring toolkit for DayZ / Enfusion `.layout` UI files.

The 0.36 distribution-ready source is being staged through the repository bootstrap pull request.

## Privacy

Selected project, dependency, vanilla GUI, layout, image, font, imageset, and EDDS files are processed locally in the browser. NIH Layout Studio does not require a server-side file-upload pipeline.
